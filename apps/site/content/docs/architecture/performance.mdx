---
title: Native UI performance
description: macOS arm64 installer size, idle memory and time to the first window.
---

Measured on November 25, 2026 with ReignHub 1.0.0-dev.20261125.11, Apple M5 and macOS 26.6.

| Measurement | Result |
| --- | --- |
| macOS arm64 DMG | 10,927,104 bytes (10.42 MiB) |
| Idle physical footprint | 54.3 MiB |
| Process launch to first visible window | 774 ms median |

Five fresh processes opened an isolated demo workspace. The launch timer ran from process creation until WindowServer reported the first visible application window. Samples were 2801, 1165, 653, 774 and 760 ms. The OS file cache remained enabled. After eight seconds at the dashboard in the fifth run, vmmap reported the physical footprint. Agent startup and remote network connections are outside this measurement.
