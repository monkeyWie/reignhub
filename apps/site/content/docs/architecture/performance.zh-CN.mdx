title: 原生 UI 性能
description: macOS arm64 的安装包体积、空闲内存和首次显示窗口的实测结果。
---

2026 年 11 月 25 日在 Apple M5、macOS 26.6 上测量，客户端版本为 1.0.0-dev.20261125.11。

| 指标 | 结果 |
| --- | --- |
| macOS arm64 DMG | 10,927,104 字节（10.42 MiB） |
| 空闲物理内存 | 54.3 MiB |
| 新进程启动至窗口可见 | 中位数 774 ms |

使用隔离演示工作区启动五次新进程，从创建进程计时，直到 WindowServer 报告第一个可见应用窗口。五次用时分别为 2801、1165、653、774、760 ms，保留系统文件缓存。第五次在工作台空闲八秒后，以 vmmap 读取进程物理内存。测量范围为客户端，Agent 启动和远程连接另计。
