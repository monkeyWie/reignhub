ReignHub 是你的 Agent 聚合工作台。在同一个项目下找到 Codex、Claude Code、Pi 等 Agent 的会话，用手机、桌面或浏览器继续工作。代码、工作目录和 Agent 仍在原来的电脑上运行。

## 三个角色

| 角色     | 运行位置              | 做什么                                  |
| -------- | --------------------- | --------------------------------------- |
| 被控端   | 安装 Agent 的桌面电脑 | 显示 Agent 接入状态，处理配对和远程指令 |
| 控制端   | 桌面、手机、浏览器    | 连接多台电脑，管理会话、发送消息和附件  |
| 连接服务 | Go 服务或 Cloudflare Worker     | 设备发现、配对信令、可用时提供加密中继  |

桌面应用同时承担控制端和被控端。浏览器和手机作为控制端，不会把你电脑上的 Agent 搬到云端运行。

## 连接你的 Agent

ReignHub 用一个 Codex 入口管理 App、CLI 和 VS Code 来源的会话，保留原来的模型账号、项目环境和会话。通过开放的 Provider 架构，还可以扩展更多 Agent。[选择接入方式](/docs/agents)。

支持 macOS、Windows、Linux、iOS、Android 和 Web。[选择你的平台](/download)，或直接打开 [Web 控制台](/web)。
