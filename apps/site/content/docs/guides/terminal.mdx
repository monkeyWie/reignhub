---
title: Remote terminal
description: Open a shell in the project directory from a conversation.
---

Open a conversation and select the terminal icon in the upper right. On desktop you can also press **Control + backtick**. The shell starts on the computer running the agent, in the project's working directory.

Paired devices can use the terminal by default and run commands as the current system user. To turn this off, open **Connection settings** on the computer running the agent and disable **Allow remote terminals**.

Use the plus button to open another tab. Each tab owns a shell. Hiding the panel, switching conversations or temporarily disconnecting leaves the shell running on the host. Closing the tab or ending the terminal stops its process. The macOS, Windows and Linux apps can host shells. The web and iOS apps connect to shells on a paired desktop.
