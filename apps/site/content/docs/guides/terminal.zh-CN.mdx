---
title: 远程终端
description: 在会话中打开项目目录中的 Shell。
---

打开会话，点击右上角的终端图标。桌面端也可以按 **Control + 反引号**。Shell 在运行该 Agent 的电脑上启动，初始目录取自当前会话的项目。

已配对的设备默认可以使用远程终端，以当前系统用户的身份运行命令。需要关闭时，在运行 Agent 的电脑上打开「连接设置」，关闭「允许远程终端」。

点击加号可新建标签。每个标签有独立的 Shell。收起面板、切换会话或暂时断线时，主机保留 Shell。关闭标签或结束终端会终止相应的进程。macOS、Windows 和 Linux 客户端可以运行 Shell，网页端和 iOS 客户端可以使用已配对电脑的终端。
