## Device IDs and names

The connection service allocates six-digit device IDs. IDs belong to that service. If you change services, pair again using the ID issued by the new service.

The device list retains names and connection information. Desktops use the system device name; browsers derive a name from browser information. Adjust the local name in settings to distinguish computers.

## Multiple computers

A controller can remember multiple hosts. Choose a device, then one of its projects and sessions. Mobile navigation moves from devices to sessions to full-screen chat; Back returns one level at a time.

On desktop, the default view is the local device dashboard. Manage local agents in **Settings → Agent**. Selecting a remote device opens that computer's sessions.

## Trust and revocation

For manual access, approve the controller on the host or set an access password. Both endpoints keep their private keys locally. To revoke a manual pairing, remove it on the host.

## Official account access

Sign in on both endpoints and select an associated host from the account device list. The first connection opens without a pairing code or host approval. Remove a device from the account to revoke its account connections. A host disconnected from the control receives the removal when it next checks in.

Free accounts can associate three hosts. Pro includes ten hosts and three simultaneous official relay connections. Controllers, Agents and sessions do not consume host slots. Self-hosted Go and Worker deployments support manual pairing without an account.
