---
title: 开源自部署
description: 选择设备配对、建立直连与转发加密流量的服务。
---

Agent 和项目运行在你的电脑上。连接服务负责配对设备、协助建立直连，并在需要时转发加密流量。所有客户端填写同一个服务根地址，浏览器直接打开这个地址下的 `/chat/`。

| 部署位置                | 安装什么                                                                         | 对外开放什么                                           |
| ----------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 自己的电脑或服务器      | [Go 服务](/zh-CN/docs/self-hosting/go)，内置 Web 控制台和 SQLite                 | 控制台和信令使用 HTTPS，STUN 与原生中继使用 TCP 和 UDP |
| 自己的 Cloudflare 账户  | [Cloudflare Worker](/zh-CN/docs/self-hosting/cloudflare)，使用 D1 和 Durable Objects | 一个 HTTPS 地址，包含加密 WebSocket 中继               |
| 给已有中控加一个公网 IP | [额外的 Go 节点](/zh-CN/docs/self-hosting/probe)，可接 Go 或 Worker 中控         | 对外公布的 STUN、中继 TCP 和 UDP 端口                  |

### 连接第一台设备

1. 打开服务地址，确认能看到 Web 控制台。
2. 在运行 Agent 的桌面客户端中，将服务地址设为同一个根地址。
3. 在手机或浏览器里输入桌面设备码，在电脑上批准配对，然后打开项目查看会话。

开源自部署无需 ReignHub 账号，费用由你选用的基础设施决定。升级时请参阅[备份与升级](/zh-CN/docs/self-hosting/operations)。
