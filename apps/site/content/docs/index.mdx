## Three roles

| Role               | Runs on                                | Responsibility                                                   |
| ------------------ | -------------------------------------- | ---------------------------------------------------------------- |
| Host               | Desktop computer with agents installed | Agent readiness, pairing and remote commands                     |
| Controller         | Desktop, phone or browser              | Connect to computers, manage sessions and send messages or files |
| Connection service | Go server or Cloudflare Worker                      | Discovery, pairing signaling and encrypted relay when available  |

The desktop app is both a host and a controller. Phones and browsers are controllers; they do not move your agents into the cloud.

## Connect your agents

Connect Codex and Codex CLI while keeping your model accounts, projects and sessions. The open provider architecture makes additional agent integrations possible. [Choose your setup](/docs/agents).

ReignHub spans macOS, Windows, Linux, iOS, Android and Web. [Choose your platform](/download) or open the [Web console](/web).
